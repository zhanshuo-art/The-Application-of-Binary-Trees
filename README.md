# Patent Keyword Analysis System

专利关键词分析系统 - 基于数据结构的专利创新数据处理与分析

## 项目简介

本项目是一个完整的专利关键词数据处理与分析系统，使用 C++ 实现了从数据预处理、二叉搜索树管理到哈夫曼编码压缩的完整流程。项目主要用于处理专利数据集中的关键词，分析其频率和新颖度，并演示经典数据结构算法的实际应用。

## 功能模块

### 1. 数据预处理模块 (`experiment_3_analysis.cpp`)

**功能：** 从原始专利数据中提取和统计关键词信息

**主要特性：**
- 解析 CSV 格式的专利数据文件
- 处理包含特殊字符的复杂字段
- 提取每条专利记录的关键词（Keywords）和新颖度（Novelty）
- 统计每个关键词的出现频率和平均新颖度
- 筛选频率 ≥ 4 的关键词并输出结果

**输入：** 原始专利数据 CSV 文件（包含 Keywords 和 Novelty 字段）

**输出：** 关键词分析结果 CSV 文件（包含 keyword, freq, avg_novelty 三列）

### 2. 二叉搜索树管理模块 (`experiment_3_BST.cpp`)

**功能：** 使用二叉搜索树（BST）高效管理和查询关键词数据

**主要特性：**
- **基本操作：**
  - 插入（Insert）：添加新关键词或更新已有关键词
  - 查找（Search）：快速检索指定关键词
  - 删除（Delete）：移除指定关键词（支持四种删除情况）

- **遍历操作：**
  - 先序遍历（Pre-order）
  - 中序遍历（In-order）：按字典序输出
  - 后序遍历（Post-order）
  - 层次遍历（Level-order）

- **高级查询：**
  - 区间查询：查找指定字典序区间内的所有关键词
  - 条件筛选：按最小新颖度和最小频率筛选关键词

**输入：** 关键词分析结果 CSV 文件

**输出：** 各种查询和遍历的控制台输出

### 3. 哈夫曼编码模块 (`experiment_3_huffmanencode.cpp`)

**功能：** 使用哈夫曼编码实现关键词的高效压缩

**主要特性：**
- 基于关键词频率构建哈夫曼树
- 自动生成最优前缀编码
- 对比定长编码与哈夫曼编码的效率
- 计算压缩率和平均编码长度

**核心算法：**
- 使用优先队列（小顶堆）构建哈夫曼树
- 递归生成哈夫曼编码
- 编码效果分析与统计

**输入：** 关键词分析结果 CSV 文件

**输出：**
- 哈夫曼编码表
- 定长编码与哈夫曼编码对比
- 压缩率统计数据

## 使用方法

### 数据处理流程

1. **数据预处理**
```bash
g++ experiment_3_analysis.cpp -o analysis
./analysis
```
修改代码中的 `inputPath` 为你的原始专利数据路径。

2. **BST 数据管理**
```bash
g++ experiment_3_BST.cpp -o bst
./bst
```
修改代码中的 `CSV_FILE_PATH` 为步骤 1 生成的结果文件路径。

3. **哈夫曼编码分析**
```bash
g++ experiment_3_huffmanencode.cpp -o huffman
./huffman
```
修改代码中的 `csvFilePath` 为步骤 1 生成的结果文件路径。

### 自定义配置

每个模块的配置项都在 `main()` 函数顶部标注了修改位置：

```cpp
// ========== 在此处填写文件路径 ==========
string inputPath = "your_file_path_here";
// =======================================
```

## 数据格式要求

### 输入数据格式（原始专利数据）
- CSV 格式文件
- 必须包含 `Keywords` 和 `Novelty` 字段
- `Keywords` 字段：双引号包围的关键词列表
- `Novelty` 字段：浮点数，表示专利的新颖度评分

### 中间数据格式（关键词分析结果）
```csv
keyword,freq,avg_novelty
voice,5,8.234
recognition,12,9.451
...
```
